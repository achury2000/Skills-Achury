# Related Projects

Skills-Achury curates material from several open-source projects. Below are
links to the original repositories for context, attribution, and further
exploration. Some projects are intentionally **not** included in this pack
due to licensing restrictions — see notes.

## Included in this pack (curated)

| Project | License | What was taken |
|---|---|---|
| [ECC (Everything Claude Code)](https://github.com/affaan-m/ECC) | MIT | Skills, agents, commands, rules |
| [Ruflo (formerly Claude Flow)](https://github.com/ruvnet/claude-flow) | MIT | Curated skills, SPARC commands |
| [security-audit-skill](https://github.com/cloudflare/security-audit-skill) | MIT | Complete skill (Cloudflare) |
| [shadcn/ui](https://github.com/shadcn-ui/ui) | MIT | `shadcn` and `migrate-radix-to-base` skills |
| [Floci](https://github.com/hectorvent/floci) | MIT | Agent rules as reference |
| [system-prompts-and-models-of-ai-tools](https://github.com/x1xhlol/system-prompts-and-models-of-ai-tools) | GPLv3 | Reference prompts collection |

## Other notable agent ecosystems

These projects are not sources for this pack, but are useful companions in
the agent-tooling space:

- [Claude Code](https://www.anthropic.com/claude-code) — Anthropic's coding agent
- [OpenCode](https://opencode.ai) — open agent harness
- [Model Context Protocol (MCP)](https://modelcontextprotocol.io) — standard for tool integrations
- [Skills CLI](https://skills.sh) — registry of agent skills
